# Oil & Gas — disconnected-cloud reference case

The shared research repository now connects local authority, signed imports, controlled changes, monitoring, permitted disclosure and clean restoration to a synthetic Oil & Gas case.

[Detailed industry case](https://github.com/cybersmeashish/sovereign-disconnected-cloud-security/blob/main/docs/industry-cases/oil-gas.md) · [Contributions 08–28](https://github.com/cybersmeashish/sovereign-disconnected-cloud-security/blob/main/docs/contributions-08-28.md) · [Original measured results](https://github.com/cybersmeashish/sovereign-disconnected-cloud-security/blob/main/research/2026-11-18-results.md)

The case identifies scoped local review authority, tenant/site boundaries, two local approvers and environment-specific acceptance questions. Shared experiments include denied cross-scope actions, signed-package rejection, filtered evidence export and clean software-key/config/data restoration.

This is synthetic reference work. No customer deployment, real transaction, public-service determination or industrial-control command is claimed. The shared container results cannot establish sector throughput, provider residency, accreditation or whole-site recovery.
